# Shikimori для Lampa (`Shikimori.js`)

Плагин для приложения **Lampa**, добавляющий каталог аниме с [Shikimori](https://shikimori.one), подробные карточки с хронологией франшизы, трейлерами и кадрами, а также двустороннюю связку с карточками **TMDB**.

---

## Возможности

- **Витрина и поиск в боковом меню Lampa** (`Аниме (Shikimori)`):
  - Подборки в один клик: **Онгоинги**, **Популярное**, **Топ рейтинга**, **Анонсы**.
  - Поиск по русскому, оригинальному (ромадзи / кандзи) и английскому названию с поддержкой голосового ввода на Android TV.
  - Бесконечная прокрутка (`scroll.onEnd`) и кнопка «Загрузить ещё».
- **Подробная карточка аниме (`ShikimoriFullComponent`)**:
  - Постер высокого разрешения (`image.original`) и автоматическая установка фона в Lampa.
  - Полная сводка: тип, статус, вышедшие/всего эпизоды (`8 / 12 эп.`), длительность, оценка Shikimori, возрастной рейтинг, дата релиза, студии, жанры, альтернативные названия.
  - Очистка описания от BBCode-разметки и автоматическое вырезание блоков `[spoiler]...[/spoiler]`.
  - Просмотр **YouTube-трейлеров** через штатный плеер Lampa и галерея кадров.
  - **Связанное (франшиза / хронология)** — быстрый переход к сиквелам, приквелам, фильмам и OVA в рамках серии.
  - **Похожее аниме** — рекомендации с Shikimori.
- **Умный переход Shikimori ↔ TMDB**:
  - Кнопка **«Найти на TMDB»** внутри карточки Shikimori ищет тайтл по оригинальному, английскому и русскому названиям, умеет отбрасывать суффиксы сезонов (`The Final Season`, `2nd Season`, `2 сезон` и т.д.) и ранжирует результаты по жанру анимации (`16`), стране (`JP`) и году выхода.
  - Обратный переход **из любой карточки Lampa на Shikimori** через контекстное меню карточки или отдельную кнопку в карточке фильма/сериала.
- **Надёжность и совместимость**:
  - Автоматическое циклическое переключение зеркал (`shikimori.one` / `shikimori.io`) и встроенный TTL-кеш запросов (защита от лимитов `429 Too Many Requests`).
  - Отмена сетевых запросов кнопкой «Назад» на пульте ТВ.
  - Строгий синтаксис **ES5** — совместимость со старыми Smart TV (Samsung Tizen, LG WebOS, Orsay, Android TV) и адаптивная вёрстка для мобильных экранов.
  - Полная локализация интерфейса (`ru`, `uk`, `en`).

## Установка в Lampa

Откройте в Lampa **Настройки → Расширения → Добавить плагин** и укажите ссылку через CDN (рекомендуется, так как отдаёт корректный `Content-Type: application/javascript` и не блокируется `X-Content-Type-Options: nosniff`):

```text
https://cdn.jsdelivr.net/gh/Arezar/shiki@main/Shikimori.js
```

*(Либо опубликуйте репозиторий через GitHub Pages и используйте URL вашего сайта.)*

---

## Настройки плагина

После установки в **Настройки → Shikimori** доступны параметры:

| Параметр | По умолчанию | Описание |
| :--- | :---: | :--- |
| **Пункт в контекстном меню карточки** | Вкл | Показывать пункт «Информация на Shikimori» при долгом нажатии на карточку |
| **Кнопка Shikimori в карточке фильма** | Выкл | Добавлять кнопку с иконкой Shikimori в блок кнопок полной карточки TMDB |
| **Кнопка только для аниме и мультфильмов** | Вкл | Скрывать кнопку в карточках обычных игровых западных фильмов и сериалов |
| **Зеркало Shikimori** | Автоматически | Выбор рабочего домена (`Автоматически`, `shikimori.one`, `shikimori.io`) |

## Разработка и проверка кода

Требуется Node.js 18+:

```bash
npm install
npm run lint   # Проверка синтаксиса ES5 и статический анализ ESLint
npm test       # Модульные и интеграционные тесты (node:test + JSDOM + jQuery)
npm run check  # Полная проверка (lint + test)
```
